Propósito de la Práctica

  • Objetivo de la Instancia: Demostrar el aprovisionamiento, encapsulación y publicación de un servidor web institucional desacoplado del sistema anfitrión.
  • Aislamiento de Recursos: El servidor opera en un espacio de nombres y sistema de archivos propio dentro de un contenedor Linux Nginx.
  • Publicación de Puertos: El puerto 8089 del anfitrión redirige el tráfico HTTP hacia el puerto estándar 80 del contenedor nginx1.
  • Mecanismo de Despliegue: Extracción de archivo original e inyección de contenido HTML personalizado mediante el comando docker cp.
⚙️

Ficha Técnica: nginx1

  • Nombre del Contenedor: nginx1
  • Imagen Base Oficial: nginx:latest (Servidor Web & Proxy Reverso)
  • Mapeo de Puerto: 8089 (Host) → 80 (Contenedor)
  • Ruta Raíz Web Interna: /usr/share/nginx/html/index.html
  • Estado Operativo: ACTIVO Y SIRVIENDO CONTENIDO
💻

Secuencia de Comandos Ejecutados

Los siguientes comandos Docker fueron utilizados para inicializar, personalizar y verificar este servidor institucional:

# 1. Despliegue del contenedor institucional en segundo plano exponiendo el puerto 8089 docker run -d --name nginx1 -p 8089:80 nginx # 2. Extracción de la plantilla base original de Nginx hacia el directorio de trabajo docker cp nginx1:/usr/share/nginx/html/index.html ./index1.html # 3. Inyección del diseño institucional personalizado hacia el contenedor docker cp index1.html nginx1:/usr/share/nginx/html/index.html # 4. Verificación de conectividad HTTP al servidor institucional curl -I http://localhost:8089
